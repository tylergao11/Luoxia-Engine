# 计划模式演示（无代码改动）

## Goal

让你看到 **Plan Mode** 的完整交互：计划文件 → 审批 →（可选）进入执行。

本计划 **不修改仓库代码**，仅作流程演示。

## 计划模式是什么

| 阶段 | 你看到什么 | 我能做什么 |
|------|------------|------------|
| **Plan** | 本文件可编辑/预览 | 探索代码、讨论、只写 plan.md |
| **Approve** | 审批 UI（通过 / 改计划） | 等你拍板 |
| **Execute** | 自动继续实现 | 改代码、跑测试（本演示跳过） |
| **Audit** | 独立审计 diff | 有实现时才触发 |

## Execution Steps

1. 你阅读本计划，确认界面与文案是否符合预期。
2. 若只想看流程：点 **拒绝/取消** 或要求改计划即可，不会动代码。
3. 若点 **批准**：我会回复「演示结束、无实现」，不提交任何工程改动。

## Impact Scope

- **会写**：仅本 session 的 `plan.md`（会话目录，非业务代码）
- **不会写**：`src/`、`contracts/`、`docs/`、git 历史等

## Risks / Irreversible Actions

无。纯演示，无破坏性操作。

## Verification

- 你能打开并阅读本计划文件
- 审批控件可见
- 批准后工作区业务文件仍无 diff（`git status` 干净）
